Vaiddisha AI: Clinical Decision-Support & Doctor Recommendation PlatformVaiddisha AI is an intelligent full-stack clinical decision-support and doctor consultation management system. The platform integrates multi-turn AI symptom triage, vision-based OCR lab report analysis, specialist doctor matching, and appointment scheduling.1. 4. Setup & Execution InstructionsPrerequisitesPython 3.11+ with uv installedNode.js 18+ and npmRunning PostgreSQL instance with database vaiddisha_dbBackend SetupNavigate to the backend directory:PowerShellcd D:\Vaiddisha\backend
Configure .env:Code snippetDATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/vaiddisha_db
GROQ_API_KEY=your_groq_api_key
Start the FastAPI server using uv:PowerShelluv run python main.py
The API server will start at [http://127.0.0.1:7861](http://127.0.0.1:7861)Interactive Swagger documentation is available at [http://127.0.0.1:7861/docs](http://127.0.0.1:7861/docs)Frontend SetupNavigate to the frontend directory:PowerShellcd D:\Vaiddisha\frontend
Install dependencies:PowerShellnpm install
Launch the Vite development server:PowerShellnpm run dev
